01可在线体验

智造协同平台

MANUFACTURING COLLABORATION PLATFORM

制造业一站式协同平台。核心是以「协同问数」为入口的智能协同五件套，配合运营看板、审批与报告形成闭环；问答走 RAG，事件走 SSE 流式，前后端分置香港与广州。

  • 智能协同五件套：协同问数 / 制度问答 / 案例检索 / 数据速查 / OA 协同
  • 问数用自然语言查工单与指标；制度问答走「云端 Embedding + BM25 + RRF」，去掉本地 Reranker 快 200–500ms
  • Agent 只提议、人签字：27 条会签权限 + 1,896 条离线测试守住越权、脱敏与降级
  • 运营视图 + 治理复盘：履约 / 制造 / SPC 看板、预警中心、审批确认、报告中心
  • 香港 Nginx / 广州 FastAPI 双机部署，SSE 关缓冲，跨机端口只对白名单开放

02可在线体验

智能 APS 排产平台

INTELLIGENT APS SCHEDULING PLATFORM

面向离散制造的排产系统：维护物料、BOM、工艺路线与订单，配置硬约束和软约束权重后求解，输出可执行的甘特计划、交付缺口与约束归因。后端 Spring Boot + Timefold，前端 Vue 3。

  • 硬约束先兜底：设备能力、换型、班次日历、物料齐套；软约束按权重优化交期与切换成本
  • 求解进度走 STOMP WebSocket 实时推送，长任务不必轮询
  • 计划结果带约束归因与缺口分析，能回答「为什么这张单排不进去」
  • 主数据 / 订单 / 排产 / 权限分层，多租户隔离，Flyway 管理数据库迁移
  • 前端香港静态托管、后端广州容器，跨机只暴露一个受白名单限制的端口

03开源 · MIT

Hogo-QA-tool

OFFLINE SPC ANALYSIS TOOL

给工厂质量人员的离线工具：导入 Excel 测量值与不良数据，得到 Cp/Cpk/Pp/Ppk、控制图判异、柏拉图与能力图；可打印、导出 Excel / Word，AI 解读是可选项。

  • 修正旧工具 std_sub = std_total 的缺陷：Cp/Cpk 用组内 σ，Pp/Ppk 用整体 σ，不再让 Pp 恒等于 Cp
  • 7 种控制图 + 12 条判异准则（W1–W4 / N1–N8），逐条开关；报表导出范围 7 项可选
  • 构建产物是单个 index.html，目标机器无需 Node；统计内核零 React / DOM 依赖，样本可复算
